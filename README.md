# Wooki Rush

Disco-swamp runner. Jump the skunk apes, slide the Wooki Bigfoots, or cut them down with the ray gun. Tap the hovering disco ball to clear the screen.

You get four hits before the board resets. Clear all 10 levels and you take the gold cup.

```bash
npm install
npm run dev
```

Turn the phone sideways. Direction pad on the left, jump and slide on the right. Ray is the round button between them.

Jump: right button or space. Slide: right button or S. Move: left pad, or A and D. Ray: button or F.
